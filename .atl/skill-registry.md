# Skill Registry & Project Standards

## Project Context
- **Project**: medicos-como-pacientes
- **Stack**: HTML5, Vanilla CSS3, Vanilla JavaScript (ES6+)
- **Testing**: Manual browser verification (no automated runner)

## Compact Rules
- Maintain HTML5 semantic structures and clean ES6+ JavaScript.
- Avoid introducing blocking code or unhandled promises in YouTube IFrame API interactions.
- Always perform empirical verification in local dev server (port 3000) before committing to main.
